# Guitar Pro conversion

StrumSight does not import Guitar Pro files directly. To practise from a
Guitar Pro score, convert your own file outside StrumSight, then import the
resulting MusicXML, MXL, or MIDI file.

## Offline workflow

1. Keep the Guitar Pro source file on your own device.
2. Use an offline conversion tool on that device to create MusicXML, MXL, or
   MIDI.
3. Check the converted file before importing it into StrumSight.

StrumSight does not upload the Guitar Pro source file and does not include a
Guitar Pro converter. It does not guarantee that the converted result preserves
every Guitar Pro detail; review the imported music before practising with it.

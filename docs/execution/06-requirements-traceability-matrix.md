## Frissítési szabály

- Issue létrehozásakor töltsd ki az Issue oszlopot.
- PR nyitásakor töltsd ki a PR oszlopot.
- `In progress` csak aktív branch mellett.
- `Verified` csak a Definition of Done és required CI után.
- `Waived` kizárólag ADR- és owner-jóváhagyással.
- A mátrix sorát nem szabad törölni; elvetett követelmény `Cancelled` státuszt és indoklást kap.
